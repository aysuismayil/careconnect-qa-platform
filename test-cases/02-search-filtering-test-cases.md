# Test Cases — Caregiver Search & Filtering

Covers location-based search, filters, sorting, and pagination. See [template](../templates/test-case-template.md) for column definitions. Related bug: [BUG-001](../bug-reports/BUG-001-search-radius-boundary-excluded.md).
