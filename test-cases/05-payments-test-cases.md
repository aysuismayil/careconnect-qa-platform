# Test Cases — Payments

Covers checkout, payment methods, receipts, refunds, and failure handling. All testing uses the payment provider's **sandbox/test mode** — no real card data. See [template](../templates/test-case-template.md). Related bug: [BUG-003](../bug-reports/BUG-003-payment-double-charge-retry.md).
